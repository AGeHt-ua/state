# Тен-Коди НПУ
Цей Регламент визначає єдині стандарти та формулювання оперативного радіозв'язку для співробітників Національної поліції України штату NG під час несення служби на стаціонарних постах, у патрульних нарядах та під час проведення спеціальних операцій.
## РОЗДІЛ I. ЗАГАЛЬНІ ПРАВИЛА ВЕДЕННЯ РАДІООБМІНУ
1.1. Радіообмін ведеться виключно державною мовою, стримано, чітко та лаконічно із застосуванням затверджених кодів зв'язку.
1.2. Під час оголошення критичних сигналів небезпеки (Code 0, Code Red, 10-90) в ефірі оголошується режим радіотиші. Усі патрулі припиняють сторонні переговори, крім доповідей по суті ліквідації надзвичайної події.
1.3. Використання оперативних кодів для розваг або передачі неправдивих повідомлень тягне за собою суворе дисциплінарне стягнення.
## РОЗДІЛ II. ОПЕРАТИВНІ КОДИ ТРИВОГИ ТА СИТУАЦІЙ
- Code 0: потрібна негайна вогнева підтримка, поліцейський перебуває під прицільним обстрілом.
- Code 4: ситуація повністю врегульована, обстановка під контролем, додаткова допомога не потрібна.
- Code Red: критична надзвичайна ситуація або збройний прорив, усім вільним екіпажам та підрозділу КОРД терміново прибути на місце події.
## РОЗДІЛ III. ДЕСЯТИЧНІ СЛУЖБОВІ ТЕН-КОДИ (10-КОДИ)
- 10-0: повідомлення або виклик відхилено (відміна дії).
- 10-4: повідомлення прийнято, інформацію зрозумів.
- 10-9: інформація не розбірлива, повторіть повідомлення.
- 10-15: правопорушника затримано, здійснюється конвоювання до відділку поліції.
- 10-20: запит місцезнаходження екіпажу або повідомлення своїх поточних координат.
- 10-23: екіпаж прибув на місце виклику чи інциденту.
- 10-34: потрібна термінова допомога / запит підтримки додаткового патруля.
- 10-90: надзвичайна подія в банківській установі / збройне пограбування банку.
## РОЗДІЛ IV. ТАКТИЧНІ КОДИ ПАТРУЛЬНОЇ СЛУЖБИ ТА ВІДПОЧИНКУ
## 1. Коди патрулювання:
- 5-1: екіпаж виїхав у призначений сектор патрулювання.
- 5-2: екіпаж продовжує несення служби та патрулювання у секторі (обстановка стабільна).
- 5-3: патрулювання завершено, екіпаж повертається до управління поліції.
- 5-7: потрібна допомога наряду / запит підкріплення на місце зупинки транспорту.
## 2. Коди перерв та відпочинку:
- 4-1: поліцейський оформив перерву та відійшов на обідній відпочинок у встановленому порядку.
- 4-2: поліцейський повернувся з обідньої перерви та готовий продовжити виконання службових обов'язків.
