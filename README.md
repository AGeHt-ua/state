# СБУ штату NG · кабінет «Сова»

Особистий кабінет співробітників Служби безпеки штату NG (NG GTA 5 RP) і Discord-бот, який є його ядром.

- **Бот** (`bot/`, Python, discord.py) — база SQLite, API для сайту, картки з кнопками в каналах відділів, ролі, бекапи. Працює на SparkedHost.
- **Сайт** (`site/`) — GitHub Pages, своєї бази не має: усе бере з бота.
- **Ретранслятор** (`relay/worker.js`) — Cloudflare Worker з постійною HTTPS-адресою, що пересилає запити сайту боту.
- **Законодавча база** (`docs/law-kb/`) — тексти законів і правил NG, вивантажені з ng-gta5.com.

## Як це працює

1. Голова СБУ видає доступ командою `/доступ видати` — бот надсилає співробітнику Static ID і пароль в особисті.
2. Під час входу на сайт бот перевіряє ролі на Discord-сервері: основна роль СБУ, звання, відділ.
3. Звіти й рапорти, подані на сайті, з'являються карткою в каналі відділу. Кнопки «Підтвердити / Погодити» працюють і в Discord, і на сайті.
4. Після погодження рапорту бот сам змінює ролі (звання, відділ) і пише в #сова-кадровий-аудит.
5. Файли зберігаються в закритому каналі #сова-сховище-файлів; сайт отримує їх через бота.
6. Кожні 6 годин стиснута база йде в #сова-бекапи. Відновлення — `/сова відновити` з файлом бекапу.

## Запуск на SparkedHost

1. Код потрапляє на сервер з цього репозиторію (Startup → `STARTUP_FILE` = `bot/main.py`).
2. У корені сервера створіть `.env` за зразком `.env.example` і впишіть `DISCORD_TOKEN` та `GUILD_ID`.
3. Боту на Discord-сервері потрібні права: керувати каналами, керувати ролями (роль бота має стояти **вище** ролей СБУ), надсилати повідомлення, прикріплювати файли.
4. Запустіть сервер. Канали категорії «СОВА · кабінет» бот створить сам.

## Команди

| Команда | Хто | Що робить |
|---|---|---|
| `/доступ видати` | Голова | Створює обліковий запис і надсилає пароль |
| `/доступ пароль` | Голова | Новий пароль, усі входи завершуються |
| `/сова профіль` | усі | Звання, відділ, бали, умови підвищення |
| `/сова бекап` | Голова | Бекап бази зараз |
| `/сова відновити` | Голова | Відновлення бази з файлу бекапу |

Попередній вміст репозиторію (портал «State») збережено в гілці `state-archive`.
