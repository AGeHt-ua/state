# Огляд проєкту State | Ukraine GTA 5 RP

Портал уряду штату Сан-Андреас для RP-сервера Ukraine GTA 5. Це публічна законодавча база, подібна до zakon.rada.gov.ua, разом з електронним кабінетом посадовців і громадян.

## Архітектура

| Частина | Де | Технології |
|---|---|---|
| Фронтенд | `frontend/` | Статичний HTML + vanilla JS + CSS, без збірки. Деплой на GitHub Pages |
| API | `worker/` | Cloudflare Worker (Discord OAuth), поки це заглушка |
| Дані | `localStorage` браузера | `frontend/assets/store.js` |

`index.html` у корені перенаправляє на `frontend/`.

### Ключові файли

- `frontend/assets/store.js` містить усю бізнес-логіку (~1250 рядків): користувачі, ролі, апарати, посади, права, документи, маршрути погодження, голосування Конгресу, звернення, заявки на зміну профілю та сповіщення.
- `frontend/assets/app.js` відповідає за спільний каркас сторінок: шапку, навігацію сайту й кабінету, пошук, футер і `pathTo()` для відносних шляхів.
- `frontend/assets/accounts.js` містить тестові акаунти (`castro`, `admin`, `doj`, `dept`, `court`).
- `frontend/assets/constitution.js` містить текст Конституції та її форматування.
- `frontend/cabinet/create/editor.js` — редактор документа A4.
- `worker/src/index.js` містить маршрути `/api/health`, `/api/login` і `/api/callback` (Discord OAuth та ролі гільдії). Маршрут `/api/me` поки заглушка.

## Розділи сайту

**Публічні:** `/` (головна), `/acts/` (база актів із фільтрами за видом, апаратом і сортуванням), `/acts/view/?id=` (картка акта), `/structure/` (органи влади), `/login/`, `/register/`.

**Кабінет (`/cabinet/…`):**
- `create/`: створення документа (редактор A4)
- `acts/`, `docs/`, `all/`: чернетки та документи
- `inbox/`: вхідні на погодження й голосування
- `appeals/`: звернення громадян (номер `ZV-РРРР-NNNN`)
- `chancery/`: канцелярія
- `court/`: суд
- `people/`: учасники та призначення
- `admin/`: апарати, посади, маршрути, статус конгресмена
- `pending/`: екран очікування для тих, кому ще не призначили роль

## Доменна модель

- **Ролі** (визначаються апаратом): `governor` (повні права), `official`, `prosecutor`, `court`, `citizen`, `pending`.
- **Апарати**: Губернатор, Директори департаментів, Прокуратура, Суд. Нові апарати створюються в адмінці й автоматично отримують посади «Керівник» і «Співробітник».
- **Рівні доступу посад**: `head`, `staff`, `admin`, `viewer` (набори з 10 прав).
- **Конгресмен** — це статус конкретної людини (`congressMember`), а не роль.
- **Статуси документа**: чернетка → на погодженні → голосування Конгресу → чинний / відхилено / втратив чинність / кошик. Для кожного документа зберігаються історія (80 записів) і версії (30).
- **Маршрут погодження** за замовчуванням: керівник апарату автора → Губернатор. Автор не може погоджувати власний документ. У Конгресі рішення ухвалюється простою більшістю голосів членів.

## Поточний стан (етап 1 з 6, див. `roadmap.md`)

Зроблено: каркас сайту, повний клієнтський документообіг, адмінка, звернення, сповіщення.

Обмеження, про які варто знати:
1. **Усі дані зберігаються тільки в `localStorage`.** Кожен браузер бачить свою копію, тому спільної бази немає. Перевірки прав і пароля виконуються в браузері — будь-хто може змінити свої дані через DevTools. Справжній захист можливий лише після переносу даних і перевірок на сервер (Worker + D1).
2. **Бета-тест: паролі зберігаються відкрито** (в `accounts.js` і `localStorage`) для зручності тестування. На сторінках реєстрації та входу є попередження не вводити реальні дані. Перед запуском авторизацію треба перенести на сервер.
3. **HTML документів санітизується** (`sanitizeDocHtml` у `store.js`) перед показом і при відкритті в редакторі: прибираються скрипти, обробники подій, небезпечні URL і CSS.
4. **На всіх сторінках є Content-Security-Policy** (meta-тег). Нові зовнішні джерела (CDN, API) треба додавати в політику.
5. **Worker**: CORS лише для `FRONTEND_ORIGIN` (можна кілька через кому), OAuth `state` проти CSRF, сесія — HMAC-підписана HttpOnly-cookie (`/api/me`, `POST /api/logout`). Фронт до Worker ще не підключено.
6. Ліміт `localStorage` становить приблизно 5 МБ, а фото й зображення в документах швидко його заповнюють.

## Локальний запуск

```bash
cd frontend
python -m http.server 8080
```

Відкрити `http://localhost:8080/` і увійти, наприклад, як `castro` / `castro`.
